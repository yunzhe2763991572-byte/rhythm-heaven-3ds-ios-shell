哈希只是用于识别已测试输入，并不包含游戏数据。工具不负责获取游戏、提供解密密钥或解密受保护的文件。

本机生成完整包需要四部分：

1. 无资源空壳 `RhythmHeaven3DS-shell.ipa`。
2. 自己的受支持 CIA。
3. 从这份 CIA 在本机重编译得到的 `Guest.framework`。
4. 本机工具准备的 OFL 开放字体与许可证。

**不能仅把 CIA 复制到已安装的空壳里就运行。** 游戏框架必须为 iOS ARM64 编译，并随完整应用一起重新签名。PC 的 DLL、macOS dylib、模拟器缓存都不能替代它。

完整包不需要在手机上另外导入 RomFS / data。原始 CIA、生成 C、游戏框架、游戏图标、共享系统字体、个人存档和密钥都不应加入公开仓库。原始输入会保留。
