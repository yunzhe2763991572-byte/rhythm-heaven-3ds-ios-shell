# 手柄连接与按键

先在 iPhone 的系统蓝牙设置配对手柄，或使用系统支持的有线连接，再打开游戏；游戏运行中连接、断开也可识别。兼容范围是 iOS 能识别为 **GameController Extended Gamepad** 的设备，并非所有蓝牙输入设备。具体型号仍需实机验证。

映射按任天堂按键的**位置**，与触屏／3DS 的游戏提示保持一致：

| 手柄位置 / 功能 | 游戏内按键 | Xbox 常见标识 | PlayStation 常见标识 |
|---|---|---|---|
| 右侧面键 | A | B | ○ |
| 下方面键 | B | A | × |
| 上方面键 | X | Y | △ |
| 左侧面键 | Y | X | □ |
| 十字方向键 | 十字方向键 | 十字方向键 | 十字方向键 |
| 左摇杆 | 十字方向键（数字方向） | 左摇杆 | 左摇杆 |
| 左／右肩键 | L / R | LB / RB | L1 / R1 |
| Menu / ＋ / Options | START | Menu | Options |
| Options / − / Share（若系统提供） | SELECT | View | Create / Share |

A、B 可以同时按住，不需要切换触屏布局。左摇杆在本游戏中作为方向键使用，不提供模拟圆垫轴；右摇杆、扳机与震动没有映射。系统自定义按键配置可能改变物理位置对应关系。

连接手柄后，虚拟方向键、ABXY 与布局切换入口自动隐藏；**START、SELECT、竖屏暂停、双屏交换和副屏触摸继续保留**，可在手柄缺少相应按键时补充操作。断开后恢复原有触屏布局，不改变已经保存的大 A / A、B 样式。横屏仍可点左上小屏交换主副屏。

只选择一个手柄：第二个手柄连接时不会抢走正在使用的手柄；当前手柄断开后可接续其他已连接的兼容手柄。断开、暂停、系统对话框、退到后台及旋转时会清理输入；跨这些操作持续按住的键需要松开再按，避免返回时卡键或误触。

升级前备份应用文档中的 `user` 存档，使用相同签名账户与应用标识覆盖安装。空壳仍不含游戏，完整 IPA 只在本机组装。代码测试与云端编译通过不等于所有手柄均已完成实机测试。
